## Design philosophy

These projects document the useful failures as well as the finished results. The collection covers PID tuning, sensor fusion, servo synchronization, compact electronics packaging, stripped servos, broken frames, wiring revisions, and the structural changes that made later builds more dependable.

Each project folder explains what its files represent, how the design evolved, and what must be checked before fabrication or powered testing.
